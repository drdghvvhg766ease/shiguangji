## 二、P1 主题引擎 + 用户自定义配色

**现状**：CSS 变量集中在 `styles.css` 与 `gallery.css` 的 `:root`（暖纸色系被灰绿系静态覆盖），无任何运行时切换机制。

**改造**：
1. **统一变量体系**：合并两套 `:root` 冲突，整理出语义化变量层（`--paper / --ink / --accent / --surface` 等），全组件统一引用。
2. **运行时主题机制**：`html[data-theme="xxx"]` 挂变量组，新增 `stores/theme.js`（Pinia），持久化到 localStorage + 后端账号（换设备同步）。
3. **自定义配色器**：在 ProfileView 增加「装扮」页——提供 4~6 套预设（暗夜、纸感手账、樱花、海盐、墨绿）+ 色盘自定义主色/背景色/强调色，实时预览。
4. **后端**：`users` 表加 `theme_preference`（JSON 字符串）字段，附 `migrate_theme.py` 幂等迁移脚本（沿用现有 inspect + ALTER 模式）。

**验收**：切主题全局生效、刷新保留、换账号各自独立。

## 三、P2 语音 / 音频记录

**现状**：`Media.kind` 仅支持 `photo|video`，上传管线在 `posts.py create_post` + `media_utils.py`，媒体读取 `media.py` 已支持 HTTP Range 流式（音频可直接复用）。

**改造**：
1. **后端**
   - `Media.kind` 增加 `audio`；配置加音频 mime 白名单（mp3/m4a/wav/ogg/webm）、单段上限（如 20MB / 10 分钟）。
   - 上传管线复用 `save_upload_stream`；有 ffprobe 时探测时长写入 `duration_seconds`，无则跳过（与视频策略一致）。
   - 规则：一条记录可以是「纯音频」「音频+文字」或「照片+音频」（照片当封面/配图），不可与视频混传。
   - `migrate_voice.py`：扩展 kind 校验与相关字段。
2. **前端**
   - ComposeView 新增「语音」录制入口：MediaRecorder 浏览器录音（计时、重录、试听），也支持上传本地音频文件。
   - 新组件 `AudioPlayer.vue`：封面 + 波形风格进度条 + 倍速；照片墙/时间线/详情页统一使用。
   - 权限提示：录音需用户授权麦克风（localhost/HTTPS 下可用）。

**验收**：录音→发布→圈内好友可流式播放/拖动/下载，sha256 校验一致。

## 四、P3 四大玩法

### 4.1 回忆盲盒
- 后端：`GET /api/circles/{id}/memory-box`——优先「往年今日」，没有则随机旧记录；每天首次打开有"拆盲盒"仪式感。
- 前端：入口放首页/时间线，拆盒动画（卡片翻开/粒子散落，tsParticles 现成）+「分享给圈子」按钮。

### 4.2 年度 / 月度回顾报告
- 后端聚合接口：照片数、足迹城市数、互动 Top 好友、最活跃月份、被赞最多的记录等。
- 前端：独立报告页（长图式排版，适合截图分享），时间线页挂入口。

### 4.3 圈友打卡 / 共同任务
- 新增表 `challenges`（题目、圈、起止时间、创建人）+ `challenge_checkins`（成员打卡记录，可关联 post_id）。
- 例：「本月一起拍 10 张天空」——圈内成员发布记录时可挂上任务，进度条展示，完成时全员通知（复用 `notify()`）。

### 4.4 猜照片升级版
- 现有「猜猜那天」基础上加：倒计时模式、积分排行榜（新表 `guess_scores` 或记于 challenge 体系）、提示卡（消耗积分看拍摄月份/地点提示）。
- 后端补提交答案与判分接口，前端加计分板 UI。

## 五、P4 全局动效升级

1. **视图切换过渡**：`App.vue` 的 `<component :is>` 外包 `<transition>`，滑动/淡入。
2. **卡片与列表**：照片墙入场错落动画、悬停浮起；时间线节点逐个浮现（IntersectionObserver）。
3. **加载体验**：骨架屏替换白屏；按钮/点赞微动效。
4. **尊重无障碍**：检测 `prefers-reduced-motion`，自动降级（项目已有该偏好支持传统）。

## 九、补充：足迹地图三维沙盘（2026-10-22 下午）

需求：把足迹地图从平面插画换成可以转动的三维立体地图。

**方案取舍**：不接在线地图服务（腾讯 / 高德等 3D 倾斜视角需要密钥与联网瓦片，和"回忆可视化而非导航"的定位也不搭），改为把本地 `china-provinces.json` 的省级边界挤出成 three.js 立体沙盘。运行时不发任何地图请求、不需要密钥，边界数据与 2D 版本同源。

新增文件：

| 文件 | 作用 |
| --- | --- |
| `frontend/user/src/utils/china3d.js` | GeoJSON → `ExtrudeGeometry`：Douglas-Peucker 抽稀、环过滤、经纬度平面投影、主题色读取 |
| `frontend/user/src/components/FootprintTerrain3D.vue` | 沙盘本体：轨道相机、省份抬升入场、足迹光柱、旅程弧线 + 流动光点、悬停/点击拾取、主题联动 |

改动文件：`components/FootprintAtlas.vue`（工具栏加「平面 / 立体」切换、懒加载 3D 组件、点城市联动右侧当月旅程）、`README.md`、`public/maps/README.md`。

**关键实现**

- 抽稀容差与最小环跨度按要素自身包围盒自适应：固定 0.06° 容差会把澳门轮廓压成一条线，改用 `span * 0.015` 后 35 个省级要素全部成形（含台港澳与南海诸岛），总计约 1.6 万三角面。
- 挤出后 `rotateX(-90°)` 会把 shape 的 y 映射成 -z，建模时先对 y 取负，保证「北远南近」。
- 描边只跟大轮廓走，几百个小礁石环不描线，避免糊成划痕。
- 配色按底色明暗分两套：浅色主题省份块往暗处压，深色主题往亮处提；主题切换由 `MutationObserver` 监听 `data-theme` 自动重上色。
- `three` 走动态 import 单独成 chunk（593 KB / gzip 152 KB），平面视角不加载 WebGL 代码；WebGL 不可用时提示并退回平面。
- 视角选择存 `localStorage`，窄屏默认平面、桌面默认立体。

**验证**：几何脚本核对 35/35 要素成形、坐标方向正确；Chrome 无头截图确认浅色 / 暗夜两套主题下立体沙盘与平面视图均正常；`npm run build`（用户端 + 管理端）通过。

## 十、第二轮完善：搜索 / 备份 / 装到桌面（2026-10-22 下午）

需求来源：用户确认「最缺的是整批导出与备份、全站搜索、手机上像 App」，并补充「手机也要、Web 端也要」。AI 相关（语音转文字、文案生成、照片打标签）因涉及费用或效果不稳，本轮跳过。

### P5 全局搜索

| 层 | 文件 | 内容 |
| --- | --- | --- |
| 后端 | `app/routers/search.py`（新） | `GET /api/search`：跨用户所在所有圈搜索 `content / location_name / activity_tag` 与分册 `title / prompt`；支持 `circle_id`、`member_id`、`date_from/date_to`、`kind=photo|video|audio|text`、分页；返回高亮摘要、首图预览、标签与地点候选 |
| 前端 | `components/GlobalSearch.vue`（新） | 浮层搜索结果面板：类型 / 圈子 chips、日期与成员折叠筛选、关键字分段高亮、↑↓ 选择 + Enter 打开、移动端全屏、`Ctrl/⌘ + K` 唤起 |
| 前端 | `App.vue` | 桌面顶栏与手机顶栏各加搜索入口；搜索结果点击打开记录详情（跨圈自动按 `post.circle_id` 鉴权），分册结果会先切换当前圈再打开 |

要点：
- LIKE 通配符做了转义（`%`、`_`、`\`），搜索 `%` 不会变成全表匹配。
- 越权保护：`circle_id` 不在自己圈子列表时直接返回空结果，不泄露存在性。
- 排序：当前圈优先（MySQL `FIELD()`），圈内按生活日期倒序。
- 结果面板 10.9 KB / gzip 4.6 KB，懒加载，不使用时零成本。

### P6 整圈 ZIP 导出

| 层 | 文件 | 内容 |
| --- | --- | --- |
| 后端 | `app/models.py` + `migrate_export.py`（新） | `export_jobs` 表：状态机（pending → running → ready / failed）、范围、体积、记录数、媒体数、过期时间 |
| 后端 | `app/routers/exports.py`（新） | 创建 / 查询 / 下载 / 列表四个接口，`BackgroundTasks` 后台打包，过期任务与文件自动清理 |
| 前端 | `components/CircleExport.vue`（新） | 圈子页「数据备份」卡片：日期范围、生成按钮、轮询进度、下载、最近导出列表；手机端纵向布局 |

压缩包结构：
```
时光迹_我们仨_2026-01-01_2026-12-31/
  照片/2026-10-11_林芝市_007_01.jpg
  视频/…
  语音/…
  记录清单.csv      ← utf-8-sig，Excel 直接打开
  records.json      ← 含经纬度、SHA-256、媒体映射
  README.txt
```

要点：
- 媒体用 `ZIP_STORED`（照片视频本身已压缩，再 deflate 只是白耗 CPU），文本用 `ZIP_DEFLATED`。
- 单包上限 3 GB，超限直接失败并提示缩小日期范围；源文件缺失记为 `skipped`，不中断整包。
- 权限：圈内成员可导出，任务只有创建者能查与下载；下载链接 72 小时后失效。
- 实测：10 条记录 / 13 个媒体 → 613 KB，解压后目录、CSV、JSON、README 全部正确。
